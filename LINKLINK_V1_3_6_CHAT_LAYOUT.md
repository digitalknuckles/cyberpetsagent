# LinkLink v1.3.6 — Desktop Chat Lane and Response Avatar

Based on v1.3.5 responsive Trainer commands package.

- Desktop (>=1200px): chat viewport and composer share a centered lane of at most 50% workspace width, capped at 720px. Trainer, Missions and Adventure panels capped at 50% width (700px).
- Assistant bubbles align left with composer input; collector bubbles align right. Dark shaded conversation background.
- Each assistant bubble receives an active NFT portrait on its left edge, half revealed. Thinking state animates more quickly while loading; response state uses subtle floating movement.
- Mobile/tablet retain full available viewport width and compact portrait sizing.
- Respects reduced-motion settings.
- No backend, database, NFT metadata, authentication, or XP modifications.

Static validation: JavaScript syntax check, ZIP CRC check. Browser testing still required.
