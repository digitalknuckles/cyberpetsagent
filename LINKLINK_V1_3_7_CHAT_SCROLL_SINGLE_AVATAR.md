# LinkLink v1.3.7 — Conversation Scroll and Single Active NFT Avatar

Based on the complete v1.3.6 desktop chat avatar release.

- Chat and input composer participate in the same flex-column layout, preventing chat from extending behind the input.
- Chat scrolls internally and auto-scrolls to new responses.
- Only the newest LinkLink response carries an animated avatar; previous avatars are removed.
- The active NFT image appears fully visible to the left of the active response bubble and updates on NFT selection.
- Reduced-motion preferences remain respected.
- No changes to wallet authentication, NFT metadata, pet progression, trainer reward logic, or server APIs.

Test on desktop and mobile: long conversations, typing spinner, response completion, NFT switch, viewport resize and keyboard appearance.
